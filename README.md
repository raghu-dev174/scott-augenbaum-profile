# Scott Augenbaum landing page (plain HTML)

Static site: index.html + styles.css + img/. No build step, no dependencies.

## Deploy
- Vercel: drag this folder into vercel.com/new, or run `npx vercel --prod` inside it. Framework preset: Other. No build command, output directory `.`
- Netlify: drag the folder onto app.netlify.com/drop
- Any host: upload the three items (index.html, styles.css, img/) to the web root.

## Edit
Open index.html, change the text, save and re-upload. Colours and fonts are CSS variables at the top of styles.css.
